# A4 Portfolio — Mukhamad Muhdzor Al Maksum

## Files
- `index.html` — main portfolio
- `style.css` — layout and A4 print styling
- `script.js` — print/PDF and HTML download actions

## How to use
1. Open `index.html` in Chrome/Edge.
2. Replace `[your email]`, `[your LinkedIn]`, and `[your GitHub]`.
3. Replace each `PROJECT SCREENSHOT` placeholder with your actual project screenshots.
4. Press **Print / Save PDF**.
5. In the print dialog:
   - Paper size: **A4**
   - Scale: **100%**
   - Margins: **None** or **Default** (the document already controls the margins)
   - Enable **Background graphics**
   - Destination: **Save to PDF**

The design is based on the visual direction of the original Al Maksum portfolio: dark hero section, cyan/purple accent, Poppins/Inter typography, technology badges, project cards, and modern minimal sections, adapted into fixed A4 pages.
